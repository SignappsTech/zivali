# C16 i18n catalogues and formatting (`@zivali/i18n`)

## Files

`packages/i18n/messages/<locale>/<namespace>.json`, locales `sl` (source, default) and `en`. One namespace per feature, owned by the task that creates it:

`common`, `errors` (one key per C1 error code), `nav`, `footer`, `auth`, `profile`, `pets`, `breeds`, `attributes` (species, size, sex, colours, patterns), `report_lost`, `report_found`, `report` (detail), `browse`, `map`, `location`, `photos`, `matches`, `chat`, `notifications`, `email`, `alerts`, `share`, `poster`, `abuse`, `lifecycle`, `support` (tips, contributions), `payments`, `ads`, `partners`, `consent`, `admin`, `pages` (public page copy, from content slices), `legal` (titles; long text lives in MDX), `deeplink` (P2 content §5 deep-link landing: `invalid_title`, `invalid_body`, `invalid_action`; the mobile `+not-found` screen, TASK-12.7).

Keys: `snake_case`, max 3 levels (`report_lost.steps.photo.title`). ICU MessageFormat for plurals and selects:

```json
{ "browse": { "results": "{count, plural, one {# prijava} two {# prijavi} few {# prijave} other {# prijav}}" } }
```

## Build and check

- `pnpm --filter @zivali/i18n build` merges namespaces into `dist/sl.json`, `dist/en.json` (consumed by both apps and the API worker).
- `pnpm --filter @zivali/i18n check` fails on: a key present in one locale only; different ICU placeholders between locales; SL plural messages without `one`, `two`, `few`, `other`; EN plural without `one`, `other`; empty strings. Runs in CI.

## Runtime API

- Web (next-intl): `useTranslations('<ns>')`, `getTranslations` in server components, `useFormatter`. Locale from the path; `NEXT_LOCALE` cookie; on sign-in, profile locale wins and the user is redirected to the same page in that locale.
- Mobile (use-intl): `<IntlProvider locale messages timeZone="Europe/Ljubljana">`; locale from profile → stored choice → device (`en*` → en, else sl); `setLocale(l)` persists locally and to the profile.
- Server (API worker, Node): `import messages from '@zivali/i18n/dist/sl.json'` + `createTranslator({ locale, messages })` from `use-intl/core` for emails and push.

## Formatting

`@zivali/i18n/format`: `formatDate(d, locale, 'short'|'long'|'time')`, `formatRelative(d, locale)`, `formatEur(cents, locale)` (`5,00 €` in SL, `€5.00` in EN), `formatDistanceBand(band, locale)`, `formatCount(n, locale)`, `formatDayMonth(date, locale, now?)` ("12. oktobra" in SL, the genitive month that Intl does not decline; "12 October" in EN; with the year when it is not the current one; P9 dates such as "Pogrešana od {date}" use it, and so should the web detail, TASK-18.2). All via `Intl` with `timeZone: 'Europe/Ljubljana'`.

## Example

```ts
const t = useTranslations('browse');
t('results', { count: 2 });   // "2 prijavi"
```
