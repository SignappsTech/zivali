# Glossary

One term per concept, everywhere: web, mobile, notifications, emails, posters, help pages and legal texts. If a concept is missing, ask the content strategist before inventing a synonym. Voice rules: `docs/content/voice-and-tone.md`.

# 2. Report types and statuses

`žival` is feminine, so standalone status labels agree with it.

| Concept | SL label (status word) | SL in a sentence | EN label | EN in a sentence |
|---|---|---|---|---|
| LOST report, status open | Izgubljena | izgubljena žival; izgubljen pes; izgubljena mačka | Lost | lost pet; lost dog; lost cat |
| FOUND report | Najdena | najdena žival; najden pes; najdena mačka | Found | found animal; found dog; found cat |
| SIGHTED report | Opažena | opažena žival; opažen pes; opažena mačka | Sighted | sighted animal |
| REUNITED | Spet doma | Luna je spet doma. | Home again | Luna is home again. |
| CLOSED | Zaključeno | Iskanje je zaključeno. Prijava je zaključena. | Closed | The search is closed. |
| MATCHED (owner only) | Ujemanje potrjeno | Ujemanje ste potrdili. | Match confirmed | You confirmed the match. |
| Held or hidden by moderation | V pregledu | Prijava je v pregledu. | Under review | Your report is under review. |
| Expired | Poteklo | Prijava je potekla. | Expired | The report has expired. |

Species in headings and SEO titles agree with the species, not with "žival": "Izgubljen pes", "Izgubljena mačka", "Najden pes", "Najdena mačka", "Opažen pes", "Opažena mačka". For cats we use "mačka" even for males, unless the owner set sex = male ("maček"). Search synonym: **pogrešan / pogrešana** (missing) appears in SEO descriptions and body copy, never as a status label.

# 8. Counters (ICU plural forms)

SL categories: one (1, 101 …), two (2, 102 …), few (3, 4, 103 …), other (0, 5 to 100 …). The table gives the nominative; accusative differs only where shown.

| Noun | one | two | few | other | Accusative one (if different) |
|---|---|---|---|---|---|
| prijava (report) | 1 prijava | 2 prijavi | 3 prijave | 5 prijav | 1 prijavo |
| žival (animal) | 1 žival | 2 živali | 3 živali | 5 živali | |
| pes (dog) | 1 pes | 2 psa | 3 psi | 5 psov | 1 psa |
| mačka (cat) | 1 mačka | 2 mački | 3 mačke | 5 mačk | 1 mačko |
| ujemanje (match) | 1 ujemanje | 2 ujemanji | 3 ujemanja | 5 ujemanj | |
| opažanje (sighting) | 1 opažanje | 2 opažanji | 3 opažanja | 5 opažanj | |
| sporočilo (message) | 1 sporočilo | 2 sporočili | 3 sporočila | 5 sporočil | |
| obvestilo (notification) | 1 obvestilo | 2 obvestili | 3 obvestila | 5 obvestil | |
| fotografija (photo) | 1 fotografija | 2 fotografiji | 3 fotografije | 5 fotografij | 1 fotografijo |
| uporabnik (user) | 1 uporabnik | 2 uporabnika | 3 uporabniki | 5 uporabnikov | 1 uporabnika |
| minuta (minute) | 1 minuta | 2 minuti | 3 minute | 5 minut | 1 minuto ("čez 1 minuto") |
| ura (hour) | 1 ura | 2 uri | 3 ure | 5 ur | 1 uro |
| dan (day) | 1 dan | 2 dneva | 3 dnevi | 5 dni | |
| teden (week) | 1 teden | 2 tedna | 3 tedni | 5 tednov | |
| prikaz (impression) | 1 prikaz | 2 prikaza | 3 prikazi | 5 prikazov | |
| klik (click) | 1 klik | 2 klika | 3 kliki | 5 klikov | |

Verbs agree with the count: "1 žival je spet doma", "2 živali sta spet doma", "3 živali so spet doma", "5 živali je spet doma". Put the verb inside the ICU message.

Relative time ("pred 5 minutami", "pred 2 urama", "včeraj") comes from `formatRelative` (Intl). Do not build it by hand.

ICU example:

```
{count, plural, one {Prikaži # prijavo} two {Prikaži # prijavi} few {Prikaži # prijave} other {Prikaži # prijav}}
{count, plural, one {Show # report} other {Show # reports}}
```

EN: one, other ("1 report", "2 reports").

# 11. Open points for native review and the client

1. Role labels "lastnik" and "najditelj" in chat aliases (C9) are generic masculine forms. Alternative: "Oseba, ki išče" / "Oseba, ki je našla" (longer, neutral). Proposal: keep the short forms in chat headers only, with the display name preferred when the user set one.
2. "Vpis" for sign-in instead of the more common "Prijava". Recommended because "prijava" is the core product noun.
3. "Spet doma" vs "Ponovno skupaj": we use "Spet doma" everywhere (status, screen, route) to match the tagline.
