Najdimo P23 UI kit gallery (mockup)

P23 UI kit gallery

Every core component in every state, as the one visual reference for shadcn/ui on web and React Native Reusables on mobile. Web styling at up to 1200 px; mobile-only parts (choice rows, bottom navigation, top bar, sheet) in 390 px frames. The top bar switches light, dark and side by side, Slovenian and English sample text (Slovenian runs 15 to 20 % longer), and 44 px target outlines.

Specimen rows are not views. Each frame that stands for a screen has one primary action. Ratios: contrast on the element's own surface, for the mode shown Copy: P23 content slice; "sample" in a caption = placeholder text

1. Actions

Button in five variants, three sizes and six states, and the icon button. Full pill, no border, no shadow, 16 px bold (17 on lg), icon 20 before the label with an 8 px gap. Labels never truncate.

Primary (default)

One per view. Hover and pressed mix 14 % foreground into the fill; pressed also scales to 0.98 for 80 ms (light haptic on mobile).

Secondary

Tonal, lower emphasis. Also the one button of an empty state and the boost buttons.

Ghost (with icon)

Text with a hover tone: foreground at 10 % over the surface. Here with a leading icon; while loading, the spinner takes the icon's place, so nothing moves.

Text

Teal text for the quiet second action, always 44 px high with 12 px padding. On mobile it sits under the primary.

Destructive

Delete and other irreversible actions, usually as the main action of a confirmation dialog (see 6).

Sizes

sm 44 px high (padding 18), md 48 px (padding 24), lg 56 px (padding 32, 17 px label). Same sizes for every variant except text. At large OS text the label wraps and the height grows from these minimums (see 10).

Mobile action stack

lg primary, full width, with the text button under it; 44 px from the bottom edge. Specimen pairing (the strings come from P3 and P7).

Icon button

44 × 44, 24 px bold icon, always an accessible name (here "Zapri"). Ghost style.

2. Fields

FormField: label above (15/20 bold), line input with a 2 px underline, help below (14/20), error below with an icon, tied by aria-describedby. 56 px high (64 on single-question screens), 18 px text, no box. Placeholders show an example format only, never a label.

Input

Real P6 strings: the chip number field. Hover turns the line foreground; focus adds 2 px in the ring colour; error turns it destructive; disabled is dashed, so it never relies on colour.

Textarea, select and search

Same line style and the same hover, focus, error and disabled rules as the input. Textarea starts at 96 px. Select is a line with a caret; on web it opens a listbox popover, on mobile a bottom sheet of choice rows (see 6). Search has a leading icon and a 44 px clear button. All strings here are sample copy.

3. Choices

Choice row, toggle pill, segmented control, switch, checkbox and radio. Selected is always a fill plus a check (or a dot, or the thumb position), never colour alone.

Choice row (390)

Full width, 64 px minimum, card on background, radius 20, 20 px side padding, icon 24, title 17 bold, description 14. Selected: primary fill with the check on the right. A radiogroup for species and situation; the Report menu uses the same row as a menu item with a caret (see 6).

Toggle pill

44 px, secondary fill; selected = primary fill plus a check. Filters in the filter sheet (status, species).

Segmented control

Track muted, selected segment card. Only for switching between two or three views of the same content, never for primary navigation. Built on shadcn Tabs (see 7). Sample copy.

Switch

56 × 32, track input (off) or primary (on), thumb card. The whole row is the target and the label; the thumb position carries the state as well as the colour.

Checkbox and radio

24 px box inside a 44 px target (the whole label). Checked = primary fill with a check (checkbox) or a dot (radio). Prefer choice rows for 2 to 4 options; radios are for longer lists. Sample copy.

4. Status

Status is always an icon plus a coloured word. The four words agree with "žival". Solid status colours only appear as marker rings and chart fills.

StatusLabel (icon + word)

Fill icon 16 + word 14 bold in the status-*-subtle-foreground colour. The default way to show status in rows, tiles and timelines.

Tonal pill

30 px high, 14 bold, -subtle fill, fill icon. At most one per page: the main status on a detail page, or the premium and verified marks. Never on a photo.

Solid: marker rings

3 px status ring plus a 3 px marker-ring halo, on map land. Ratios are the ring against the land.

5. Surfaces

Flat surfaces separated by tone and space: no borders, no shadows, never a card inside a card. Every surface has a skeleton in its final shape.

Card

card surface, radius 24, padding 24. Dialogs, forms and grouped content on web. Not pressable.

Pet row (390)

Photo 64 radius 20, gap 16, title 20/24, status word + time, distance right. No dividers, 20 px between rows. Pressed: accent. Sample pets.

Avatar

32, 48 and 72 px, round. Photo, or initials on secondary when there is none. Sample names.

Pet tile (web)

Photo 4:3 radius 24, title (24/32) 16 px under it, meta line: status word, then time and distance. No container, nothing on the photo. Hover underlines the title; pressed scales to 0.98. Sample pets.

6. Overlays

Dialog, bottom sheet, popover menu and toast, open, with real Slovenian text. Popover surface; shadow only here (shadow-lg for the sheet, shadow-pop for the rest). Scrim behind modals; focus is trapped and Escape closes.

Dialog on web

Centred, max 440 px wide, title 20/28. Same buttons, same order.

7. Navigation

Bottom navigation and the flow top bar on mobile, the header and tabs on web. Active is always colour plus a second cue: fill icon, underline or a raised segment.

Bottom navigation (390)

88 px including the 20 px safe area, card, no top border, four items, no count badges. Icon 26 + label 13 bold. Active = primary colour and fill icon. Prijavi is a 48 px primary circle that rises above the row; it opens the Report sheet and is announced as a button.

Flow top bar (390)

56 px: back (icon button), one bar per step (4 px high, gap 6, primary for done and current, muted for the rest, role="progressbar"), close. No title. The bar is announced as "Korak 3 od 7".

Web header

88 px, no border, on background. At most four text links, 16 semibold: the current page is foreground and underlined, others muted. Right: language, ghost "Vpis", sm primary "Prijavi" (the one primary). Strings from P1.

Tabs

The segmented control as shadcn Tabs, for two or three views of the same content; arrow keys move between tabs. Sample copy.

8. Feedback

Skeleton, empty state, inline error and progress. Loading keeps the final layout, so nothing jumps when content arrives; errors say what happened and offer the next step.

Skeleton

muted with an accent shimmer, in the exact shape of the final element; static under reduced motion. "Nalaganje …" is announced once in a live region. Rows, tiles, cards and avatars are in 5.

9. Map

The calm map (land, water, parks, main roads and area names only) with every marker. A real map shows at most avatar, lost area and cluster, plus the sighting dot on detail maps; this specimen shows all five for reference. Markers have accessible names, and every report is also in the list.

10. Accessibility checks

Focus ring on every control, 44 px targets ("44 px targets" in the top bar outlines every hit area), contrast numbers beside every state above, status never by colour alone, text at 200 % and reduced motion.

Focus ring on every control

3 px ring, 2 px offset, fill unchanged, never removed. Ring on background and on card.
