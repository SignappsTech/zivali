P8 Pet profiles

Owners register pets ahead of time so a loss report takes seconds. The list leads with one primary action ("Dodaj žival"); the form is line fields in sections, one section per screen on mobile, one page with a sticky summary on web. The chip number is never shown publicly; an invalid chip only warns. Free limit: 2 pets (app_config pets.free_limit), the API answers PET_LIMIT. Copy from the P8 content slice v0.2.

A. Mobile (390 px)

Lives under the Profil tab. Add and edit run as a five-section flow: back, five bars, close; focus goes to the h1 on each section; sticky bottom bar with 44 px bottom padding.

B. Mobile and web region crops

Dashed outline = a state that changes one part of a screen. Same tokens and components as the frames.

C. Web (1200 px)

Signed-in header from P1 with "Moje živali" current. Single column list; edit is one page with a sticky summary; detail is two columns.
