P5 Location picker and fuzzed public area

One picker for every "where" (lost, found, sighted, alert area, home area) and the one way an approximate public location is drawn. Accurate for the reporter, approximate for everyone else. The pin stays in the centre and the map moves under it. Copy from the P5 content slice.

A. Mobile picker

Full screen inside a flow: top bar, the question, a line search field, the map, and a fixed panel with the address, "use my location", the radius (lost only), the privacy line and the one primary button.

B. Mobile search: results, searching, no results

Typing turns the field into a combobox. Results are plain rows (place, municipality); choosing one closes the list and centres the map there. The keyboard is not drawn.

C. Mobile exceptions: GPS denied, outside Slovenia, very large radius, offline (lost and found)

None of these block the report. Each uses the one note the view allows, or the help line, with an icon and words, never colour alone.

D. Alert area variant, short screen and landscape

The same screen for the P13 alert area, the short-screen collapse of the privacy line, and the landscape split.

E. Web: inline column and dialog

Inline in a flow step (centred 560 px column, map 400 px under the field), or as a dialog when launched from a flow step. Keyboard: arrows nudge the map, + and − zoom; the slider has a number input alternative.

F. Fuzzed public area (display component)

Used by the detail page (P9), the map (P4) and sightings. A translucent marker-area disc to scale, never smaller than 500 m for lost and 150 m for found or sighted, always with the area name as text. The exact point is only drawn for its owner or reporter.
