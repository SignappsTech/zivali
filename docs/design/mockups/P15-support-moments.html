P15 Support moments

Two quiet, optional asks: a thank-you contribution on the reunited screen (P14) and a collapsed contribution row at the end of the lost-report confirmation (P6 M9), plus the checkout hand-off, the four return states and My payments. No amount is pre-selected, Pay and Skip are the same variant and size, nothing blocks reporting, matching or alerts, and neither ask is rendered for anonymous finders. Copy from the P15 content slice v0.1.

A. Mobile

B. Tip block states (mobile, 390 px crops)

Each crop replaces the tip block of M1 from the pills down; everything above stays as drawn. Web uses the same states with the two buttons side by side (W1).

C. Contribution row at the lost-report confirmation (P6 M9, 390 px crops)

The last thing on M9, under the poster, share and 24-hour links. Collapsed by default, shown once per report, gone after Skrij or a payment. Replaces the sample strings in P6 M9 and C2.

D. Return states (mobile sheets, 390 px crops)

Each sheet takes the place of the success sheet in M3, over the screen the payment started from. Focus moves to the sheet heading.

W. Web

P1 signed-in shell (header links omitted here). The header "Prijavi" is secondary because the page has its own primary. Pay redirects straight to Stripe Checkout (test mode); the return page replaces the view, then "Nazaj na prijavo" brings back the report.

Plain list, newest first, no cards or dividers, 20 px between rows. Line: payments.row (date · purpose · amount, formatEur, tabular-nums). Status is icon plus word: Plačano (check), Neuspešno (warning, destructive), Vrnjeno (return arrow, muted). "Testno" on every row outside production. Potrdilo is a text button with the date and amount in its name; failed rows have none. The header "Prijavi" stays primary here: the page has no other primary.
