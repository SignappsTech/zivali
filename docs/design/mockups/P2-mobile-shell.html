P2 Mobile shell

The native frame every app screen sits in: four-item bottom navigation, the single Report action and its sheet, permission primers with their fallbacks, signed-out tabs, deep-link landing, and the shared loading, empty, error, offline and toast patterns. Phones 390 px wide. Copy from the P2 content slice; strings that belong to other pages are marked as samples in the notes.

A. Tabs and the Report action

Exactly four items, icon above a 13 px bold label, no count badges. Tabs look the same signed in and signed out.

B. Permission primers and denied fallbacks

Shown once, before the OS prompt, as a full-height sheet: spot icon, h2, two sentences, lg primary, "Ne zdaj". Denial never blocks: the place that needed the permission gets a quiet note and a working alternative.

C. Deep-link landing (listing link or poster QR)

A brief loading frame with the logo and the shape of the detail page, then the report (P9). Failures land on calm pages with one way back to the map. Without the app the same link opens the web page.

D. Shared patterns: offline, toast, loading, refresh, inline error

As in P1, with sheets instead of popovers. One notice at a time. The empty state is in B7.
