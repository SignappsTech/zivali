Najdimo P19 Admin console shell (mockup)

P19 Admin console shell

Web only, desktop first. One shell for the client's staff and moderators: a dark-teal sidebar filtered by role, a 72 px top bar, a placeholder dashboard, the shared dense table with its drawer and destructive dialog, the audit log, and the access screens (authenticator code, enrolment, access denied, session timeout, last-admin guard). Same tokens and calm tone as the public product, just denser. Shell copy is final from the P19 content slice; table data is sample.

2. Access screens

The console sits behind the normal sign-in (P16) plus an authenticator code. First-time admins enrol with a QR code. People without the role see a plain refusal with no hint of what exists. An expired session keeps the page open behind a dialog.

F7 · Strong authentication, every sign-in: after the standard sign-in (P16) · wrong or expired code (error state) · one primary
