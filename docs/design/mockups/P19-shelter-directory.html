P19 Shelter directory

Admins keep the municipality-to-shelter directory (17 shelters, 212 municipalities) correct without developer help, and every save is live at once on the public shelter pages (P3 T5, T6) and the P6, P7 and P9 call rows. Two views of the same data (shelters, municipalities) in the shared dense table, an edit drawer, history with before and after, a CSV import with a dry run, and the delete guard. Copy is from the P19 content slice (section 8); all shelter, municipality, phone and person data is sample.
