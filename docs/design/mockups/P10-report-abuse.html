Entry: the message menu or "Prijavi in blokiraj" in the conversation header (P12). The note field is the line textarea (2 px input underline, focus = ring underline plus 2 px); it grows to 5 lines, then scrolls. The counter shows only in the last 50 of 500 characters, right-aligned, tabular figures, polite (announce at 50, 20 and 0, not every keystroke); at 0 typing stops, no error. On web the confirmation, error, rate-limit and already-reported states replace the dialog content exactly as in M3, M4, S2 and S3.
