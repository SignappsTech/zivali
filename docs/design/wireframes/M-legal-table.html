Račun in nastavitveprikazno ime, e-naslov, zgoščeno geslo ali identiteta pri Googlu oziroma Applu, jezik, vloga (na primer lastnik, najditelj ali zavetišče), domače območje, privzeti polmer opozoril, neobvezna telefonska številka (nikoli javna), tihi čas, nastavitve obvestil, žetoni za potisna obvestila

Ali morate podatke posredovati? Brez računa lahko brskate in anonimno prijavite najdeno ali opaženo žival. Za račun potrebujemo e-naslov ali vpis z Googlom oziroma Applom. Druga polja, na primer telefonska številka, so neobvezna. Če podatka, ki ga funkcija nujno potrebuje, ne podate, te funkcije ne moremo zagotoviti.

Legal table (all legal tables use this one component). Desktop: a real table with a filled header row, a 30 % label column in bold, 16 px cell padding, top-aligned text, 1.6 line height and a 2 px divider (or zebra) between rows. At 390 (container under 640 px) each row becomes a card: the label is the card heading, the value sits under it. The element stays a table with explicit ARIA roles (role=table|row|rowheader|cell) and a visually hidden header row, so screen readers keep the header association; display:block alone would drop table semantics in some browsers. Print keeps the plain table. Tables with more columns (cookie list: name, purpose, duration, provider) show each cell as "label: value" lines inside the card via data-label. Source text: privacy policy §3, verbatim (13 rows).
